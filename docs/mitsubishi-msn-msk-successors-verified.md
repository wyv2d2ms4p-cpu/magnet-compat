## 3. 生産中止と代替形名（メーカー資料の記載）

### 3-1. 電磁接触器

| 生産中止 | 代替（推奨） | 出典・生産中止時期 |
|---|---|---|
| S-K65 | S-N65 | S3（2001年4月末で生産中止）。S3 の電磁接触器の表で、S-K の 50・65・80・… の行の代替が S-N の同じ番号になっている（2026-10-21 の取得は要約で、S-K65 の行の原文は引用していない）。S3 の文「原則として、形名の『K』を『N』に置き換えたものが代替機種」 |
| S-N65 | S-T65 | S5（受注停止 2017年1月末、生産停止 2017年2月末）。原文「S(D)-(2X)N65 → S(D)-(2X)T65」 |
| S-N11 | S-T12 | S4（受注停止 2015年9月末、生産停止 2015年10月末）。原文の表「S-N11, S-N12 → S-T12」 |

- S6：S-N11 → S-T12 は「互換有り（35×50）」「補助接点増（1極⇒2極）」。数値と行の対応は抽出テキストで読み取れない。
- S9：可逆形 S-2×N11 の定格は AC220V 13A・2.7kW、開放熱電流 20A（**単体の S-N11 の値ではない**）。

### 3-2. サーマルリレー

| 生産中止 | 代替（推奨） | 出典 |
|---|---|---|
| TH-K60 | TH-N60 | S3（サーマルリレーの表の「TH-K60 → TH-N60」の行。2026-10-21 の取得は要約で、原文は引用していない） |
| TH-K60KP | TH-N60KP | S3（原文「TH-K60KP → TH-N60KP」） |
| TH-N60 | TH-T65 | S5（抽出テキストで「TH-N60 TH-T65」が同じ行に並ぶ） |
| TH-N20 | TH-T25 | S5（同「TH-N20 TH-T25」） |
| TH-N20TA | TH-T50 | S5（同「TH-N20TA TH-T50」） |

- **KP（2E式）の代替形名は、S4・S5 に書かれていない。** S5 は「上記形名品を母体とした特殊仕様品(MSO-N35KP 等)についても対象となります」と書くだけ。TH-N20KP → TH-T25KP、TH-N60KP → TH-T65KP のような KP どうしの対応は、**メーカー資料では確かめていない**。
- **TH-N12 の代替形名は、S4・S5 で確かめていない**（S4 のサーマルの行は TH-N18 → TH-T18 だけ）。S6 には TH-N12 の整定範囲の変更「0.12～11A ⇒ 0.12～15A」があるが、新しい形名との対応は抽出テキストで読み取れない。
- S6 の整定範囲の変更（どの形名の組かは読み取れない）：「0.12～11A ⇒ 0.12～15A」「1.3～15A ⇒ 0.12～15A」「0.24～15A ⇒ 0.24～22A」。

### 3-3. TH-N20・TH-N20TA の仕様（S7・S8）

| 形名 | 整定電流調整範囲・ヒータ呼び | 組み合わせる接触器 | 素子数・保護 |
|---|---|---|---|
| TH-N20 | ヒータ呼び 0.24～15A（整定範囲 0.2～18A 参考） | N20・N21・N25・N35 | 2素子・過負荷保護 |
| TH-N20TA | 整定範囲 18～34A、ヒータ呼び 22A・29A | 22A は N25・N35、29A は N35 | 2素子・過負荷保護 |

- 設備リストでは TH-N20TAKP が S-N25 と組になっている。S7 から、**ヒータ呼びは 22A**（N25 に組めるのは 22A だけ）と読めるが、現物の銘板で確かめていない。
- TH-N20TA の代替 TH-T50（S5）は、**このアプリの登録値**（メーカー資料ではない）では 24〜54A・取付先 S-T35・S-T50 で、S-N25 の代替 S-T25 には組めない形になる。**S-N25＋TH-N20TAKP（22A）を、S-T25＋どのサーマルに置き換えるのかは、資料からは決まらない。**

### 3-3-2. 技術資料集 S10 で読めたこと（2026-10-21 に追記）

- 動作特性曲線の見出しに「TH－N12（TP/KP）形」「TH－N20（KP）形」「TH－N20TA（KP）形」「TH－N60（KP）形」と、母体と KP 付きの形名が並べて書かれている。**KP 付きの型式のヒータ呼び・整定範囲・組み合わせる接触器の表は、抽出テキストでは読み取れない。** 母体と同じ値かどうかも、資料の文では確かめていない。
- 「S－N11 （1a付）」の記載がある（本体の補助接点が 1a）。定格使用電流は、表の並びから 200～220V で 13A と読めるが、列の対応がずれている可能性があり確定しない。kW は読み取れない。
- 「XP」の記載は無い。KP の意味の定義も、この資料の抽出テキストには無い。
