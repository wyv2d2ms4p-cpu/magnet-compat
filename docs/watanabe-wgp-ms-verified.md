## 1. 型式コード表（仕様書から書き起こし）

形式：`WGP-M[機種]-[入力信号][出力信号]-[電源]`

- 機種：`MP` ポテンショメータ変換器（非絶縁）応答時間25ms ／ `MS` ポテンショメータ変換器（絶縁）応答時間25ms
- 仕様書にはコードの枠が並んでいるだけで、**ハイフンの位置は資料に書かれていない**（WGP-FZ と同じ事情）。
  依頼者の判断（2026-09-20、WGP-FZ のときと同じ）：型式は英数字で特定し、資料に無いハイフン位置は判断材料にしない。

## 2. 共通仕様（MP / MS）

| 項目 | 値 |
|---|---|
| 入力信号 | ポテンショメータ抵抗値 |
| 出力信号 | 直流電流／電圧 |
| 基準精度 | ±0.1%fs（23℃にて） |
| **応答時間** | **25ms（0〜90%）** |
| 許容負荷抵抗 | 電流出力：出力端子間の電圧降下15V以下／電圧出力：負荷電流2mA以下（出力1Vfs未満は1µA以下） |
| スパン調整範囲 | 定格入力の50%〜100%（マルチターントリマ） |
| ゼロ調整範囲 | スパンの0%〜50%（マルチターントリマ） |
| 使用温湿度範囲 | −5℃〜＋55℃、90%RH以下（非結露） |
| 温度特性 | ±0.015%fs/℃ |
| 絶縁抵抗 | 100MΩ以上（DC500V）入力−出力−電源各端子間相互（絶縁タイプ） |
| 耐電圧 | AC2000V 1分間 入力−出力−電源各端子間相互（絶縁タイプ） |
| 消費電力 | 約4.5VA（AC）、約90mA（DC） |
| 外形寸法 | 105（H）×25.6（W）×136.5（D）mm |
| 質量 | 約200g |
| 構造 | 薄形プラグイン（本体部とソケット部で構成） |
| 取付方法 | DINレール取付または壁面取付 |

注記：測定範囲の幅がポテンショメータ定格の50%以上である必要がある。調整はゼロ→スパンの順。

端子配列：1 INPUT HIGH／2 SLIDE／3 LOW（入力信号）、4 NC、5・6 出力（+/−）、7・8 電源（U(+)/V(−)）
**3線式入力で、WGP-FZ（入力は1・2の2端子。FZ 仕様書の端子配列）とは端子の使い方が違う。**
WGP-DS の端子配列はこのメモでは確認していない（初版で DS も2端子と書いたのは出典の無い記述だったため削除）。

## 6. 気づいたこと（今回の登録とは別件）

- `2105A-06` という表記は、WGP-FZ の仕様書と WGP-MP / MS の仕様書の**両方**に載っている。

  つまり同じシリーズの中でも値が2つあり、**この表記が何を表すかは資料から読み取れない**。
  （初版で「シリーズ単位の版の記号の可能性が高い」と書いたのは、DS/DE の値と合わない推測だったため撤回。
  また初版で挙げた WVP-MP の `2206A-06` は検索結果の抜粋で見たもので、仕様書を取得して確かめてはいない。）
- 今回の登録では、WGP-FZ にならい「ページ表記 2105A-06」と書き、「資料番号」とは呼ばない。
  既存データの「資料番号」という呼び方を見直すかは、設計文書の PR で扱う。
