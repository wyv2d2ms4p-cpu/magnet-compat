## 1. 端子配置図・信号割付（p.2、テキスト抽出から書き起こし）

| 端子 | 標準の割付 | 入力がラインドライバ・パルスの場合 |
|---|---|---|
| ① | P（＋） POWER | 同左 |
| ② | N（－） GND | 同左 |
| ④ | ＋ OUTPUT 1 | 同左 |
| ⑤ | － OUTPUT 1 | 同左 |
| ⑥ | N.C | OUTPUT2 Y（第2出力がラインドライバ・パルスの場合） |
| ⑦ | ＋ OUTPUT 2 | OUTPUT2 Z（同上） |
| ⑧ | － OUTPUT 2 | OUTPUT2 COM（同上） |
| ⑨ | EX（※1） | INPUT A |
| ⑩ | ＋ INPUT | INPUT B |
| ⑪ | INPUT COM | INPUT COM |

- ※1：「外部供給電源無し時は N.C.」（EX はセンサ供給電源の端子）
- 原文の注記：「点線内：⑨～⑪入力仕様ラインドライバ・パルス時の信号割付」「⑥～⑧第 2 出力仕様ラインドライバ・パルス時の信号割付」

## 2. 入力が1回路であることの根拠

- 入力に使う端子は ⑨〜⑪ の1組だけ。標準では ⑩（＋INPUT）・⑪（INPUT COM）、センサ供給電源付きでは ⑨（EX）を加える。
- ラインドライバ・パルス入力の「INPUT A・INPUT B」は、**RS-422 の差動信号の2本（1回路）**で、WRPP のような2相（A相・B相）の別回路ではない。ブロック図でも「入力信号 A／入力 COM／ライン レシーバ／B」が1つの波形整形回路につながっている。
- p.3 の入力の接続例（無電圧接点・オープンコレクタ入力／電圧パルス入力／2線式センサ）も、すべて ⑩・⑪（と ⑨）の1組で描かれている。
- よって **MS3749 は入力1回路**（相数1）と読める。

## 3. 同じ版で読めた、代替検討に関わる記載（参考）

- 信号絶縁：「入力－第１出力－第２出力－電源－大地各間 絶縁」。耐電圧は「第 1 出力－第 2 出力間：500V AC 遮断電流 0.5mA 1 分間」
- 一方で型式コードの注記に「第 1、第 2 出力の組み合わせで TTL レベル、電圧パルスをご指定の場合、同電位になります」とある。**電圧パルス同士（例：出力コード 4・4）の組み合わせでは、第1出力と第2出力が同電位**と読める。
- 出力論理：「極性反転ｽｲｯﾁ付 出力論理表をご参照下さい」。表は図のため、無電圧接点の ON／OFF と出力の対応は読めていない。
- 入力 O：「無電圧接点、オープンコレクタ（検出電源 約12V、3.3kΩ）」。p.3 の接続例に「+13V」「3.3kΩ」とある。

## 4. 入力の検出レベルと出力の定格（同じ Rev.1.90 から。2026-09-27 追記）

**版の注意は0章と同じ**：登録済み14件の出典は Rev.2.10 で、以下は Rev.1.90 から読んだもの。

### 入力（型式コード表 p.1）

| コード | 原文 |
|---|---|
| O | 無電圧接点、オープンコレクタ（検出電源 約12V、3.3kΩ） |
| A | AC 電圧パルス（スレッシュ電圧：約 0.06Vp-p） |
| D | DC 電圧パルス（スレッシュ電圧: SH 約 2V） |
| I | DC4～20mA パルス（スレッシュ電流：SH 約 8mA） |
| L | ラインドライバ・パルス（受信素子：RS-422 レシーバ相当） |
| Y | 上記以外指定入力信号、スレッシュ電圧 |

入力部（p.1）：
- 入力抵抗：電圧入力型 通電時 1MΩ以上（標準仕様、5V 入力時）、停電時 10kΩ以上
- 入力許容電圧：DC電圧入力型 50V DC max. 連続
- 入力パルス幅：2.5μs 以上（ON/OFF とも）

**入力 D の読み**：H と見る電圧のしきい値は「SH 約 2V」、入力に掛けてよい電圧は 50V DC まで。
比較：WGP-FZ の入力14（電圧パルス、大信号）は [1]:5V以上30V以下、[0]:1.5V以下（docs/watanabe-wgp-fz-verified.md）。
→ MS3749 の D は、FZ の14 より**低い電圧（約2V）から H と見て、高い電圧（50V）まで受ける**。
　FZ を MS3749 の代わりに使うと、センサの H が 5V 未満、または 30V を超える現場では受けられない。
　逆に MS3749 を FZ の代わりに使うと、FZ の資料の範囲（H 5〜30V・L 1.5V以下）の信号は、MS3749 のしきい値（約2V）で区別できると読める。

### 出力（p.1「型式コード」・p.2「出力部」）

- 型式コード（p.1）の第1出力信号：「１: TTL レベル」「２: オープンコレクタ」「３: 電圧パルス 10Ｖ±10%」「**４: 電圧パルス 12Ｖ±10%**」。第2出力信号：「未記入：なし」「５: ラインドライバ・パルス（RS-422 ドライバ出力）」「他は、第 1 出力信号のコードと同じ」
  → **±10% は出力電圧 12V の許容差**と、型式コードの文言から読める（2026-09-27 追記）

- 最大出力負荷：TTL レベル（最大出力 10mA＠3.5V）／電圧パルス 10V（最大出力 7mA＠±10%）／**電圧パルス 12V（最大出力 7mA＠±10%）**／ラインドライバ・パルス（TIA/EIA-422-B 準拠）
- オープンコレクタ：最大定格 30V 100mA
- 最大出力周波数（パルスホールドなし時）：電圧パルス出力時 200kHz／ラインドライバ・パルス出力時 200kHz／オープンコレクタ出力時 100kHz（負荷抵抗 2kΩ以下）
- 型式コードの注記（p.1）：「第 1、第 2 出力の組み合わせで TTL レベル、電圧パルスをご指定の場合、同電位になります。」
- Lo レベルの電圧の数値は、この版のテキストからは読めない。
