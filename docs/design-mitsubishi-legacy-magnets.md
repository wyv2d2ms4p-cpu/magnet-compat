### D64. 設備リストが根拠の5型式の `evidence.model` に、メーカー資料の URL も置く

- **決めたこと** … S-K65・S-N11・TH-K60KP・TH-N20KP・TH-N20TAKP の `evidence.model` は、`state: "verified"` で、
  `srcNote` に設備リストの記述（3-2）と生産中止・代替の出典（S番号の資料名）を書き、`srcUrl` にその資料の URL を置く。`checkedAt` は持たない（D40 の前例）。
- **理由** … 報告書 2-1・項目1。M2VS（`docs/design-insulation-converter.md` 14-8）はメーカー資料に個別の型式が無く、`srcNote` だけだった。
  今回は S3・S4 などの生産中止の資料に形名そのものが載っているので、②の「型式 確認済」からメーカー資料に飛べるようにする。
- **選ばなかった案** … M2VS と同じく `srcNote` だけにする。
- **画面** … ②の「型式 確認済」の出典がメーカー資料へのリンクになる。
- **注**（この文書を書くときに気づいた点。値は決めていない）… 報告書 2-1 の表では、TH-N20KP の実在の根拠は「設備リスト」だけで、S番号の資料が挙がっていない。
  メモ 3-3-2（報告書のあとに追記された S10）には動作特性曲線の見出し「TH－N20（KP）形」がある。TH-N20KP の `srcUrl` にどの資料を置くかは PR-B2 で決める（13章の17）。
  - （PR-D で足した注）**決まった。** 依頼者の決定（2026-10-26。PR #74 の依頼文）で S10（技術資料集 SH(NA)3539）にした。`6b94e1a` の TH-N20KP の `evidence.model.srcUrl` は S10 の URL（15章）。

### D65. 設備リストに無い TH-K60・TH-N20TA も登録する

- **決めたこと** … TH-K60（S3）と TH-N20TA（S5・S7）を登録する。どちらも設備リストには無い。
- **理由** … 報告書 2-1・項目2。検索は1件だけ当たると確定して②へ直行する（F4）。TH-K60KP だけを登録すると、「TH-K60」と打った人は
  黙って TH-K60KP（2E）の②に着く。TH-N20TA と TH-N20TAKP も同じ。
  TH-K60 は TH-K60 → TH-N60 → TH-T65 の2段の後継に S3・S5 の出典があり、TH-N20TA は TA → TH-T50 の代替（S5）を画面に出せる。
  TH-K60 は整定範囲を持たないので、他の画面は変わらない（9章。報告書が1件だけ足して測った）。
- **選ばなかった案** … TH-K60 を登録しない（「TH-K60」の検索が TH-K60KP に直行する）／TH-N20TA を登録せず、TH-N20TAKP の `note` で触れるだけ（「TH-N20TA」の検索が TH-N20TAKP に直行する）。
- **画面** … 「TH-K60」「TH-N20TA」と打つと、それぞれの②に直行する。KP の型式に黙って着かない。

### D66. KP の3型式に `discontinued: true` を付ける

- **決めたこと** … TH-N20KP・TH-N20TAKP・TH-N60KP に `discontinued: true` を付ける。**これはメモの資料の読みで、資料が明記していることではない**ことを、`note`（3-3）とこの文書に書く。
- **理由** … 報告書 2-3・項目3・4章の4。S5 は「上記形名品を母体とした特殊仕様品(MSO-N35KP 等)についても対象となります」と書く（メモ 3-2）。
  KP の型式をこの「特殊仕様品」に当てはめた。付けないと②に生産終了が出ず、そのまま発注されうる。
- **選ばなかった案** … `discontinued` をキーごと不在にする（資料が明記していないことに合わせる形。②に生産終了が出ない）。
- **画面** … 3型式の②に「生産終了」のバッジと「新規発注はできません」が出る。後継は持たない（3-1）ので「後継は ○○ です」は出ない。
- **注**（PR-D で足した）… 読みであることを書く `note` の文は、依頼者の決定（2026-10-26。13章の18）で「生産終了は、メーカーの生産終了のお知らせにある『母体とした特殊仕様品も対象』という記載から読んだもので、KP の形名そのものは書かれていません。」になった。
  3型式の `note` の D75 の文の直前に入っている（3-3 の注・15章）。

### D67. TH-N20TA の整定範囲は S7 の「整定範囲 18〜34A」で登録する

- **決めたこと** … TH-N20TA の `setRangeA` は `{min: 18, max: 34}`（S7「整定範囲 18～34A」）。
  ヒータ呼び 22A・29A を合わせた範囲で、「1台のダイヤルで回せる範囲」ではないことを `note` に書く（3-3）。
- **理由** … 報告書 2-3・項目4。S7 の見出し「整定電流調整範囲」と同じ語の値。
  既存の TH-N20 の `setRangeA`（0.24〜15A）はヒータ呼びの範囲で入っていて、同じ系列で読み方が混ざる。この食い違いは直さず 6章に残す。
  範囲の意味の問題は `docs/design-common-alternates.md` 10章の課題2 と同じ。
- **選ばなかった案** … ヒータ呼びの範囲（22〜29A）で登録する（既存 TH-N20 の読み方に寄せる。この場合の③は測っていない。13章の16）。
- **画面** … TH-N20TA の③に、メーカー指定の後継品 TH-T50 と判定の候補15件が出る（7章・9章）。既存のサーマル16画面の③に TH-N20TA が1件増える（9章）。

### D69. `regress` に分類 C を足す

- **決めたこと** … `tools/regress.mjs` の「説明できる増えた候補」に、分類 `C. 移行元に無い型式（追加レコード）が候補に加わった N 件` を足す。
