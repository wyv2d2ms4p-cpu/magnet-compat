## 重要：多重定格（LD / ND）について

FR-E800 の3相電源入力仕様品は、**定格電流と過負荷耐量の異なる2つの定格**を
パラメータ `Pr.570 多重定格選択` で切り替えられる。

| 定格 | 過負荷電流定格 | 位置づけ |
|---|---|---|
| **ND**（初期設定） | 150% 60s、200% 3s | **形名の容量表記・電流コードはND基準** |
| LD | 120% 60s、150% 3s | 過負荷を必要としない用途向け。容量を1ランク落とせる |

**互換判定の主スペックには ND定格出力電流 を使うこと。**
形名 `FR-E820-3.7K-1` の代替表記が `FR-E820-0175` であり、
この4桁コードは **ND定格出力電流 × 10**（0175 = 17.5A）であることを、
本カタログの全電圧クラスで確認済み。

単相入力仕様品（FR-E820S / FR-E810W）には LD定格の設定がなく、ND のみ。

## 注記（カタログ本文より）

1. **適用モータ容量**は、4極の三菱電機標準モータを使用する場合の最大適用容量。
2. **定格出力容量(kVA)** は、出力電圧が3相200Vクラスは230V、3相400Vクラスは440Vの場合の値。
3. カタログの定格電流欄には括弧付きの値が併記されている（例：17.5 (16.5)）。
   これは**周囲温度が40℃を超えた状態で `Pr.72 PWM周波数選択` を2kHz以上に設定して
   低騒音運転を行う場合の低減値**であり、通常条件の定格ではない。
   本ファイルの表には**括弧なしの通常値のみ**を記載している。
4. 単相入力仕様品（E820S / E810W）は、入力が単相でも**モータへの出力は3相200V**。

## 補足：既存シードデータについて

`data/_seed/inverter-generated.json` の `FR-E820-3.7K` に `ratedCurrentA: 17.5` が
入っており「FR-A800系と同値のため汚染の疑い」とされていたが、
**公式値も 17.5A であり、この値自体は正しかった**ことが本カタログで確認できた。

ただし当時「公式で確認できていないシード値をコピーしない」と判断したことは
手順として正しい。今回は公式出典に基づいて値を入れる。
