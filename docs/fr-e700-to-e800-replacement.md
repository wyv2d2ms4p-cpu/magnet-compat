## 3. FR-E800 外形寸法・取付寸法

出典：資料A p.4〜14 の外形寸法図に併記された寸法表。単位 mm。

### 3-1. 記号の意味

資料Aの図中記号。**W1 / H1 が取付寸法（取付穴間隔）であることは、資料A内の
別記述との突合で確認済み**（下の「3-4. 検算」参照）。

| 記号 | 意味 |
|---|---|
| W | 外形幅 |
| W1 | 取付寸法（幅方向） |
| H | 外形高さ |
| H1 | 取付寸法（高さ方向） |
| D | 外形奥行 |
| D1 | 奥行方向の内訳寸法。**具体的な定義は資料の図を読めていないため未確定。登録しないこと** |

### 3-3. 奥行に関する注記（資料Aより）

- 内蔵オプション装着時、FR-E800 は奥行寸法が **約27.6mm 大きくなる**。

  上表の D は資料Aの寸法表の記載値であり、**タイプ違いによる差は反映していない**。

### 3-4. 検算（W1/H1 が取付寸法であることの確認）

| 3相200V 3.7K：取付 W=158→128mm | FR-E820-3.7K-1 の W1=128 | ○ |
| 3相400V 0.4〜1.5K：外形 W=140→108mm | FR-E840-0.4K/0.75K/1.5K の W=108 | ○ |

## 6. 参考：パラメータ移行

資料A p.19〜25 に、E700 → E800 のパラメータ対応表（約200項目）がある。
本ファイルには転記していない。必要になった時点で別ファイルとして起こすこと。

| Pr. | 内容 |
