| | N | 12V 電圧パルス（最大周波数 100kHz） |
| | J | RS-422 ラインドライバ・パルス（最大周波数 1MHz） |
| ④出力の論理（第1・第2出力共通） | N | 非反転 |
| | R | 反転 |
| ⑤供給電源 | M2 | 100～240V AC（許容範囲 85～264V AC、47～66Hz） |
| | R | 24V DC（許容範囲 ±10％） |
| | R2 | 11～27V DC（CE対象外） |

## 3. 仕様（仕様書から）

### 構成：**2相（A相・B相）× 2出力**

- 「ロータリエンコーダの2相パルス入力信号を絶縁して2出力に分配（入力周波数=出力周波数）」
- 「入出力仕様の異なる2系統のパルスアイソレータとしても使用可能」
- 端子接続図（テキスト抽出から読んだもの。**図の罫線は読めていないので、現物のソケット表示で要確認**）：
  - 入力 A相：8・9 ／ 入力 B相：10・15
  - 第1出力 A相：4・12 ／ 第1出力 B相：5・6
  - 第2出力 A相：1・11 ／ 第2出力 B相：2・3
  - 供給電源 U(+)・V(−)：7・14。**取扱説明書の点検②「端子番号⑦－⑭間をテスタの電圧レンジで測定して下さい」で確認**（2026-09-27）
- つまり**1台で 入力2回路・出力4点**。既存のパルスアイソレータ（MS3749・WGP-FZ）は入力1回路・出力1点または2点（MS3749 には1出力型もある）。

### 入力（無電圧スイッチ）

- 最大周波数：100kHz
- 入力検出電圧／電流：5V DC／10mA
- 検出レベル／抵抗値：オフ 3.0V以上／750Ω以上、オン 2.0V以下／333Ω以下
- 入力パルス検出方法：直流カップリング方式

### 出力（12V 電圧パルス）

- 12V±20%。最大周波数 100kHz（入力信号の最大周波数との低い方）。許容負荷抵抗 2.4kΩ
- Lレベル電圧：0.5V以下

### 共通

| 項目 | 値 |
|---|---|
| 応答遅れ時間 | 12V電圧パルス・オープンコレクタの場合 0.2～2μs |
| アイソレーション | 入力－第1出力－第2出力－電源間（**第1出力と第2出力の間も絶縁**） |
| 耐電圧 | 入力－第1出力－第2出力－電源－大地間 2000V AC 1分間 |
| 絶縁抵抗 | 100MΩ以上／500V DC |
| 消費電力 | 交流電源：100V ACのとき約4VA、200V ACのとき約5VA、240V ACのとき約6VA |
| 使用温度範囲 | -5～+55℃ |

### 外形寸法（2026-09-27 追記）

外形図（NG-2222 Rev.3）と取扱説明書（NM-2222 改 2）の外形寸法図は、同じ数値の並びだった：
`80・50・72・107・136・（3.3）・80・20・60・72・7.8`、端子ねじ「14ーM3.5」、取付穴「2ーφ4.5（深さ25）」。

図そのもの（線と寸法の対応）はテキスト抽出では読めないため、**同じ W・UNIT で11ピンの WYPD の外形図と数値を比べて**読んだ：

| | WYPD（11ピン、`11ーM3.5`） | WRPP（14ピン、`14ーM3.5`） |
|---|---|---|
| 1つ目の図の数値 | 80・50・107・136・（3.3） | 80・50・**72**・107・136・（3.3） |
| 2つ目の図の数値 | 80・20・**40・50**・7.8 | 80・20・**60・72**・7.8 |

- 共通の 80・50・107・136 は、エムジーの信号変換器のシリーズ一覧（https://www.mgco.jp/products/signal/ 、2026-09-27 取得）の W・UNIT の代表寸法「W 50・H 80・D 136」と一致する。
- WRPP だけが、2つ目の図で 40→60・50→72 と大きく、1つ目の図にも 72 が加わっている。14ピンのソケットが11ピンより幅広い（72mm）と読める。
- よって **外形の最大寸法は 高さ 80mm × 幅 72mm（ソケット）× 奥行き 136mm、本体の幅は 50mm** と読める。
- **ただしこの読みは2つの図の数値の比較から出したもので、図の線を見て確かめてはいない。** 依頼者が外形図 PDF を目で見て確かめるまでは、推定として扱う。
- 2026-09-27、依頼者が外形図を目で見て、72 がソケットの横幅であることを確かめた

### 取扱説明書から読めたこと（2026-09-27 追記）

- 電源の入切の直後は動作が不安定で、**誤パルス（50 ms 以下）が出力されることがある**
- すべての性能を満足するには **10 分の通電**が必要
- 入力モニタランプ：A 相 緑・B 相 赤、**入力 Lo 時に点灯**（入力開放時は不定）。前面扉を開けて見る
- 出力負荷：オープンコレクタ 50 V DC 100 mA 以下／12 V 電圧パルス 2.4 kΩ以上
- 入力周波数の上限：無電圧スイッチ・12 V/24 V 電圧パルス 100 kHz 以下
- 絶縁クラス（EU 指令適合品として使う場合）：入力・第1出力・第2出力－電源間は強化絶縁（300 V）、入力－第1出力－第2出力間は基本絶縁（300 V）
- 梱包：変換器（本体＋ソケット）1台

### まだ読めないもの

- **論理（非反転・反転）の対応**：取扱説明書 P3「入出力の位相の関係と出力の論理」の図に、無電圧スイッチの OFF/ON と出力 H/L の対応が描かれているが、テキスト抽出では線の対応が読めない。依頼者が図を目で見れば確かめられる。
